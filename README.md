# Промо-сайт библиотеки компонент по BEM-методологии

Сайт доступен на [GitHub Pages](https://alexey-ryabkov.github.io/bem-comps-lib/).

## Комментарии к реализации

Для БЭМ используется схема именования `someBlock__itsElement_elementsModificator_modificatorsValue`

  
## Локальный запуск

```bash
npm i # установить зависимости проекта (сборка тестировалась с NodeJS версии 22.14)
npm start # запуск в prod-режиме на локальном веб-сервере
npm run dev # запуск в dev-режиме
```
